# Ticket Template

Use this template when creating new tickets in `thoughts/shared/tickets/` or `thoughts/<user>/tickets/`.

---

```markdown
# [TICKET-ID] Title

## Status
<!-- pending | in-progress | blocked | done -->
pending

## Priority
<!-- p0-critical | p1-high | p2-medium | p3-low -->
p2-medium

## Description
<!-- What needs to be done and why -->

## Acceptance Criteria
<!-- Measurable conditions that must be true when this ticket is complete -->
- [ ] Criterion 1
- [ ] Criterion 2

## Context
<!-- Background information, links to related tickets/PRs/issues, or relevant research -->

## Notes
<!-- Implementation notes, decisions made, or open questions -->
```
